# OrangeGadgets - 日常小工具集 / Daily Utility Scripts

这是一个主要服务于我个人日常需求的小工具仓库，用来快速解决工作、学习和生活中遇到的具体问题。工具以按需开发、够用为先，持续收录和完善。

This is a personal collection of small scripts and desktop utilities created to solve specific everyday needs across work, study, and daily life.

## AI 生成声明 / AI-Generated Content

本项目中的代码基本均由 AI 根据我的需求描述生成。我主要负责提出需求、试用工具、反馈问题以及确认最终效果。因此，本项目更适合作为个人实用工具集和 AI 辅助开发实践，而非经过全面人工审计的通用软件产品。涉及重要数据时，请在使用前自行评估并做好备份。

例外：`pdf2wordx` 的原始源代码来自 Tutos Rive 的同名开源项目，并非本项目或 AI 原创；OrangeGadgets 仅对其进行了简体中文翻译和必要的项目集成，详情见该工具目录中的来源说明。

Most of the code in this repository is generated by AI from my requirements. My role is primarily to define needs, test the tools, provide feedback, and approve the final results. This repository is best viewed as a personal utility collection and an AI-assisted development practice rather than a fully human-audited software product. Please evaluate the tools and back up important data before use.

Exception: the original `pdf2wordx` source code comes from Tutos Rive's open-source project and is not original work by this repository or by AI. OrangeGadgets only provides a Simplified Chinese translation and the integration needed for this tool collection.

## 工具列表 / Tools

| 工具 / Tool | 说明 / Description |
|---|---|
| [pdf_merger](./pdf_merger/) | Acrobat 风格的 PDF 合并与转换工具。支持缩略图预览、展开单页拖动排序、夜间模式，以及 PDF、图片、DOC、DOCX 转换。 |
| [pdf2wordx](./pdf2wordx/) | 将 PDF 离线转换为 DOCX 的桌面工具。基于 Tutos Rive 的开源项目 pdf2wordx v2.1.1，仅进行简体中文翻译与项目集成。 |
| [img2pdf](./img2pdf/) | 多张图片合并为一个 PDF。支持拖放到脚本或命令行调用。 |

## 使用方式 / Usage

每个工具独立放在自己的子目录中。进入对应目录查看安装和使用说明。

Each tool lives in its own subdirectory. See the README in that directory for setup and usage.
