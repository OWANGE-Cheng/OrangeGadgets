# OrangeGadgets - 日常小工具集 / Daily Utility Scripts

各种一次性解决小需求的脚本和桌面工具，持续收录。

A collection of small scripts and utilities that solve everyday needs.

## 工具列表 / Tools

| 工具 / Tool | 说明 / Description |
|---|---|
| [pdf_merger](./pdf_merger/) | Acrobat 风格的 PDF 合并与转换工具。支持缩略图预览、展开单页拖动排序、夜间模式，以及 PDF、图片、DOC、DOCX 转换。 |
| [img2pdf](./img2pdf/) | 多张图片合并为一个 PDF。支持拖放到脚本或命令行调用。 |

## 使用方式 / Usage

每个工具独立放在自己的子目录中。进入对应目录查看安装和使用说明。

Each tool lives in its own subdirectory. See the README in that directory for setup and usage.
